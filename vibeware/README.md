# Vibeware

Software that can feel use and move, with a threshold.

The shared loop is a funnel, not a pile of work:

```
capture → qualify → candidate → validate → promote
```

A real user population qualifies what gets written next. An agent writes the candidates. Humans hold only the boundaries: consent, money, keys, private data, and protocol compatibility. Most signals die at qualification. That is the design.

The personal loop is the same nerve on one key. SHAcollision ran that version first: a health-stats app wired to his own fitness ring, so the software could feel his readings and change. The essay generalizes from that experiment.

“Living software” already names runtime agency (one person, one session, one adapting instance). Bitdefender used “vibeware” for vibe-coded malware. Neither is this.
